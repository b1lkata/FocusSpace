# Privacy

The web app contacts music providers for searches, metadata, artwork and streaming, and LRCLIB for lyrics. These providers receive request details such as queries and network addresses according to their own policies. GitHub Pages may process hosting requests.

Likes, playlists, preferences, searches and listening history are saved in browser storage on the current origin. They do not sync between devices. Imported audio remains local unless the user explicitly shares files through another application. Clearing browser storage removes saved data.

No account system, application analytics or advertising SDK is implemented. Sharing starts only when requested by the user; chosen targets receive the shared content. No provider credentials are bundled in this repository or website.
