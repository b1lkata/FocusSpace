# Manrope

Unmodified variable font from the Google Fonts Manrope directory, downloaded 2026-10-03:
https://github.com/google/fonts/tree/main/ofl/manrope

Font: Manrope[wght].ttf, saved locally as Manrope-Variable.ttf.
License: SIL Open Font License 1.1, included in OFL.txt and copied into both builds from public/licenses/Manrope-OFL.txt.

Typography is self-hosted; there are no runtime font requests to Google or another service. Keep the copyright/license with every distribution. Existing system fonts provide fallback when local font loading fails.
